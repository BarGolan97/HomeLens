# 🏠 HomeLens — Control Your Home with a Look

**Control your smart home on Apple Vision Pro with floating buttons placed right where you need them.**

[**Download on the App Store**](https://apps.apple.com/us/app/home-lens-control-your-home/id6740048252)

---

## ✨ Features

- **Floating control buttons** for your smart devices, placed anywhere in your room
- **AR-powered dashboard** with real-time device status
- **Look-and-pinch control** of lights and other connected devices
- **Works with Apple Home**: uses your existing HomeKit setup

---

## 🛠️ Built With

- **Swift** · **SwiftUI** · **visionOS**
- **Smart home:** HomeKit
- **Distribution:** App Store Connect

---

## ▶️ Running the Project

1. Open `UITryingHomeLens.xcodeproj` in **Xcode** (with the visionOS SDK installed)
2. Run on an **Apple Vision Pro** with HomeKit devices set up in the Home app
3. Press **Run** (⌘R)
